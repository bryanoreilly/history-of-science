# Contributing

## Principles

- Keep one canonical page per person, place, theory, experiment, technology, mathematical idea, or source.
- Link to canonical records from learning paths instead of duplicating long summaries.
- Preserve uncertainty. Use approximate dates and uncertainty labels when the evidence requires them.
- Cite specific claims whenever possible.
- Prefer durable, research-friendly notes over polished but unsupported narrative.

## Filenames

Use lowercase kebab-case:

```text
isaac-newton.md
universal-gravitation.md
university-of-cambridge.md
```

## Dates

Use ISO dates when known. Use historical forms when precision is not known:

```text
1687-07-05
1687
c. 1543
4th century BCE
unknown
```

Never manufacture precision.

## Links

Use repository-relative Markdown links for files:

```markdown
[Isaac Newton](../02-people/isaac-newton.md)
```

Use wiki-style links only in rough notes if the target file does not exist yet.
